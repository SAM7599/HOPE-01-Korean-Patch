## 이 패치는 무엇을 하나요

HOPE 01은 게임 내부가 **Construct 3 엔진 + WebView2(내장 브라우저)**로 만들어져 있습니다.
이 패치는 게임 데이터(대사, 아이템, UI 문구 등)와 이미지 리소스, 게임 실행 스크립트를
한글화된 버전으로 교체하고, 한글이 깨지지 않도록 전용 한글 픽셀 폰트를 함께 적용합니다.

| | |
|---|---|
| 🧩 **설치/제거** | 배치(`.bat`) 파일 하나로 처리 |
| 💾 **백업** | 설치 전 원본 파일 자동 백업 → 언제든 원상 복구 가능 |
| 🈶 **폰트** | 한글 전용 픽셀 폰트 자동 적용 |

## 번역 범위

- 대사, 선택지, 아이템 이름/설명, 퀘스트, 업그레이드, 튜토리얼, 표지판, 메뉴/설정, 엔딩,
  엘리베이터 층 이름(모노레일층/패브리커토리/정비층/방주 프로젝트 등)까지 포함해서
  **3331/3335 (약 99.9%)** 번역 완료했습니다. (남은 4개는 극히 예외적인 케이스)
- **그림(이미지) 속 글자도 한글화**: 버튼, 설정 화면, 홀로그램 사인, 은행/보관함 안내
  문구, 모노레일·레일 선택 화면, 레일 타이머 등 이미지에 직접 그려진 문구까지 새로
  그려 넣었습니다
- 회피 키 표시가 실제 키 이름 대신 "조작"으로 잘못 나오던 버그 수정
- 로고, 낙서, 간판 같은 순수 장식용 그림 글자는 번역하지 않고 원본 그대로 둡니다

> [!TIP]
> 게임이 앞서해보기 특성이라 자주 업데이트되기 때문에 번역 커버리지는 버전마다 조금씩
> 달라질 수 있습니다. 정확한 수치는 각 릴리즈의 `CHANGELOG_vX.X.md`에 적어둡니다.

## 설치 방법

1. **[Releases](../../releases)**에서 최신 버전의 `.zip` 파일을 내려받습니다.
   *(압축 비밀번호는 릴리즈 노트에 안내되어 있습니다)*
2. 압축을 풀고 `HOPE01_KR_Patch.bat`을 더블클릭합니다.
3. 이용 안내/주의사항 화면이 먼저 나옵니다. 아무 키나 누르면 메뉴로 넘어갑니다.
4. 메뉴에서 **`1. 설치`**를 선택합니다. Steam 라이브러리를 자동으로 찾으며, 못 찾으면
   게임 폴더(`Hope 01.exe`가 있는 폴더)를 직접 선택하는 창이 뜹니다.

설치와 제거 모두 이 파일 하나로 처리되며, 실행할 때마다 깃허브에 더 새 버전이 있는지
조용히 확인해서 있으면 메뉴 화면에 안내가 표시됩니다 *(자동으로 받거나 실행하지는 않습니다)*.

## 제거 방법

`HOPE01_KR_Patch.bat`을 실행하고 메뉴에서 **`2. 제거`**를 선택합니다.

- 인벤토리/보관함에 한글로 저장된 아이템 이름 등이 있다면, 제거 전에 영문으로 되돌릴지
  먼저 물어봅니다 (예를 선택하면 자동으로 처리되고, 세이브는 실행 전 자동 백업됩니다).
- 이후 설치 전 백업해둔 원본 파일로 게임을 되돌립니다.

<details>
<summary>백업을 찾지 못하는 경우</summary>

Steam의 **[속성] → [설치된 파일] → [파일 무결성 검사]**를 실행하면 게임 파일이
원본으로 복구됩니다.

</details>

## 오래된 세이브를 계속 쓰고 계신가요? (실험적 기능)

패치 이전부터 쓰던 세이브를 그대로 이어서 플레이하면, 예전에 한 번이라도 화면에
나타났던 글자(표지판, 대화창, 아이템 이름 등)가 세이브 파일 안에 그 당시 상태(영문
또는 예전 버전 번역)로 캐시되어 있어서, 패치가 최신이어도 일부 텍스트가 계속 영문이나
빈 칸으로 보이는 경우가 있습니다.

메인 메뉴의 **`3. 실험적 기능`**에서 이런 경우를 해결할 수 있습니다.

| 번호 | 기능 | 언제 쓰나요 |
|---|---|---|
| 1 | **화면/세이브 텍스트 표시 문제 해결** | 표지판/대화창/힌트 텍스트가 영문·빈칸으로 보일 때. 세이브 캐시 + WebView2 캐시를 한 번에 정리 |
| 2 | **세이브 텍스트 번역 원복** | 패치를 **제거하기 전**에 실행 — 세이브 속 한글을 영문으로 되돌려 제거 후 글자 깨짐 방지 |

두 기능 모두 실행 전 세이브를 자동으로 백업합니다.

## 주의사항

> [!WARNING]
> - **비공식 팬 번역**입니다. 오역이나 표시 오류가 있을 수 있으며, 게임 자체의 결함(예:
>   하얀 화면 멈춤)까지 책임지지는 않습니다. 패치 적용 여부는 전적으로 이용자의 자유로운
>   선택이며, 세이브 파일을 포함한 게임 데이터에 예기치 못한 영향이 생기더라도 이를
>   보증해 드리기는 어려운 점 양해 부탁드립니다.
> - HOPE 01은 **앞서해보기(Early Access)** 게임이라 자잘한 업데이트가 매우 잦습니다.
>   게임이 업데이트되면 Steam이 패치 파일을 원본으로 덮어써서 다시 영어로 보일 수
>   있습니다. 이 경우 패치를 다시 실행해서 설치를 선택하면 됩니다. **패치 대상 버전과
>   실제 게임 버전이 다르면 아무 파일도 바꾸지 않고 설치를 자동으로 건너뛰므로** 안심하고
>   실행해도 되며, 새 업데이트에 맞는 패치는 보통 며칠 내로 올라옵니다.
> - 설치 프로그램은 정식 서명이 없는 개인 배포용 스크립트라, Windows Defender(SmartScreen)나
>   일부 백신이 "위험할 수 있음" 경고를 띄울 수 있습니다. 개인정보 수집이나 다른 프로그램
>   설치 같은 동작은 하지 않습니다. 걱정되시면 실행 전 [VirusTotal](https://www.virustotal.com)에
>   파일을 올려 직접 검사해보셔도 됩니다.

## 안전장치

- ✅ 설치 전 원본 파일을 자동으로 백업하며, 언제든 제거(원본 복구)할 수 있습니다.
- ✅ 게임이 업데이트돼서 버전이 패치와 다르면 아무 파일도 바꾸지 않고 설치를 자동으로 건너뜁니다.
- ✅ 패치 파일 자체도 설치 직전에 손상 여부를 자동으로 점검한 뒤 적용합니다.
- ✅ 세이브 파일을 직접 수정하는 실험적 기능들은 실행 전 항상 세이브를 자동으로 백업합니다.

## 게임 화면이 몇 분 뒤 하얗게 멈추는 문제 (White Screen Freeze)

> [!IMPORTANT]
> 이 현상은 **패치 때문이 아니라 원본(영어) 게임에서도 동일하게 발생하는 문제**입니다.
> HOPE 01은 WebView2 기반으로 만들어진 게임이라, PC 환경에 따라 WebView2/그래픽 드라이버
> 쪽에서 문제가 생기면 몇 분 후 화면이 하얗게 멈추는 증상이 나타날 수 있습니다.

아래 방법을 순서대로 시도해보세요.

1. **Steam 오버레이 끄기**: Steam → 설정 → 인게임 → "게임 중 Steam 오버레이 사용" 체크
   해제 (또는 게임 속성 → 일반 → Steam 오버레이 사용 해제)
2. **다른 오버레이 프로그램 끄기**: Discord 화면 공유 오버레이, Razer Cortex/Synapse,
   RGB 소프트웨어, 지포스 익스피리언스 인게임 오버레이(Alt+Z), 녹화 프로그램(OBS 등)을
   모두 끄고 실행
3. **그래픽 드라이버 업데이트**: NVIDIA/AMD/Intel 그래픽 드라이버를 최신 버전으로 업데이트
4. **Windows 업데이트 / WebView2 업데이트**:
   - Windows 업데이트를 최신으로 적용
   - [Microsoft Edge WebView2 런타임](https://developer.microsoft.com/microsoft-edge/webview2/)을
     최신 버전으로 재설치
5. 그래도 해결되지 않으면 전체 화면 대신 **창모드**로 실행해보거나, 고성능 모드
   (그래픽 카드 지정)로 실행해보세요.

증상이 계속되면 Steam 커뮤니티 토론이나 개발사 문의를 통해 원본 게임 이슈로 제보해주세요.
