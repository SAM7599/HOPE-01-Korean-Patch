# HOPE 01 한국어 패치 (비공식 팬 번역)

Steam 게임 **HOPE 01**을 한국어로 즐길 수 있게 해주는 개인 제작 비공식 팬 번역 패치입니다.
개발사, 배급사, Valve/Steam과는 아무 관련이 없습니다.

## 번역 범위

- 대사, 선택지, 아이템 이름/설명, 퀘스트, 업그레이드, 튜토리얼, 표지판, 메뉴/설정, 엔딩
- 버튼, 설정 화면, 홀로그램 사인, 은행 힌트, 레일 타이머 등 **그림(이미지) 속 글자**도 한글화
- 회피 키 표시가 "조작"으로 잘못 나오던 버그 수정
- 로고, 낙서, 간판 같은 순수 장식용 그림 글자는 번역하지 않고 원본 그대로 둡니다

## 설치 방법

1. [Releases](../../releases)에서 `HOPE01_KR_Patch.zip`을 내려받습니다.
   압축 파일에는 비밀번호가 걸려 있습니다 (비밀번호: **0000**, 브라우저가 실행 파일을 위험
   파일로 오인해 자동 삭제하는 것을 막기 위한 조치입니다).
2. 비밀번호(0000)를 입력해 압축을 풀면 `HOPE01_KR_Patch` 폴더 안에 `HOPE01_KR_Patch.bat`가 있습니다.
3. `HOPE01_KR_Patch.bat`를 더블클릭해서 실행합니다 (검은 콘솔 창이 뜹니다. 정상입니다).
4. 안내/주의사항 화면이 뜹니다. 내용을 확인하고 아무 키나 누르면 메뉴로 넘어갑니다.
5. 메뉴에서 **1번(설치)** 또는 **2번(제거)**을 입력하고 Enter를 누릅니다.
6. 게임 설치 위치와 버전을 자동으로 찾아 확인합니다. 자동으로 못 찾으면 게임 폴더
   (`Hope 01.exe`가 있는 폴더)를 직접 선택하는 창이 뜹니다.
7. 완료 메시지가 뜨면 아무 키나 눌러 메뉴로 돌아가고, 3번(종료)을 눌러 닫으면 됩니다.

같은 파일을 다시 실행해서 메뉴에서 원하는 동작(설치/제거)을 다시 고르면 됩니다.

## 제거 방법

`HOPE01_KR_Patch.bat`를 실행하고 메뉴에서 **2번(제거)**을 선택하면 됩니다.
설치 전 백업해둔 원본 파일로 되돌립니다. 백업을 못 찾을 경우 Steam의
**[속성] → [설치된 파일] → [파일 무결성 검사]**를 실행하면 게임 파일이 원본으로 복구됩니다.

## 업데이트 확인

`HOPE01_KR_Patch.bat`를 실행할 때마다 이 깃허브 저장소에 더 새 버전이 있는지 조용히 확인하고,
있으면 메뉴 화면 위에 안내 문구가 표시됩니다. 자동으로 다운로드하거나 실행하지는 않으며, 안내가
뜨면 [Releases](../../releases) 페이지에서 직접 받으면 됩니다.

## 주의사항

- **비공식 팬 번역**입니다. 오역/표시 오류가 있을 수 있으며, 게임 자체의 버그까지 책임지지 않습니다.
- 게임이 업데이트되면 Steam이 패치 파일을 원본으로 덮어써서 다시 영어로 보일 수 있습니다.
  이 경우 `HOPE01_KR_Patch.bat`를 다시 실행해 설치를 선택하세요. **패치 대상 버전과 실제 게임
  버전이 다르면 아무 파일도 바꾸지 않고 설치를 자동으로 중단**하니 안심하고 실행해도 됩니다.
- `HOPE01_KR_Patch.bat`는 정식 회사가 서명하지 않은 개인 배포용 스크립트라, Windows Defender
  (SmartScreen)나 일부 백신이 "알 수 없는 게시자" 또는 "위험할 수 있음" 경고를 띄울 수 있습니다.
  개인정보 수집이나 다른 프로그램 설치 같은 동작은 하지 않으며, 경고가 뜨면
  **[추가 정보] → [실행]**을 눌러 진행하면 됩니다. 걱정되시면 설치 전
  [VirusTotal](https://www.virustotal.com)에 파일을 올려 직접 검사해보셔도 됩니다.
- 설치 전 원본 파일을 자동으로 백업하므로 언제든 원상 복구할 수 있습니다.

## 게임 화면이 몇 분 뒤 하얗게 멈추는 문제 (White Screen Freeze)

이 현상은 **패치 때문이 아니라 원본(영어) 게임에서도 동일하게 발생하는 문제**입니다.
HOPE 01은 WebView2 기반으로 만들어진 게임이라, PC 환경에 따라 WebView2/그래픽 드라이버 쪽에서
문제가 생기면 몇 분 후 화면이 하얗게 멈추는 증상이 나타날 수 있습니다. 아래 방법을 순서대로
시도해보세요.

1. **Steam 오버레이 끄기**: Steam → 설정 → 인게임 → "게임 중 Steam 오버레이 사용" 체크 해제
   (또는 게임 속성 → 일반 → Steam 오버레이 사용 해제)
2. **다른 오버레이 프로그램 끄기**: Discord 화면 공유 오버레이, Razer Cortex/Synapse, RGB 소프트웨어,
   지포스 익스피리언스 인게임 오버레이(Alt+Z), 녹화 프로그램(OBS 등)을 모두 끄고 실행
3. **그래픽 드라이버 업데이트**: NVIDIA/AMD/Intel 그래픽 드라이버를 최신 버전으로 업데이트
4. **Windows 업데이트 / WebView2 업데이트**:
   - Windows 업데이트를 최신으로 적용
   - [Microsoft Edge WebView2 런타임](https://developer.microsoft.com/microsoft-edge/webview2/)을
     최신 버전으로 재설치
5. 그래도 해결되지 않으면 전체 화면 대신 **창모드**로 실행해보거나, 고성능 모드(그래픽 카드 지정)로
   실행해보세요.

증상이 계속되면 Steam 커뮤니티 토론이나 개발사 문의를 통해 원본 게임 이슈로 제보해주세요.
