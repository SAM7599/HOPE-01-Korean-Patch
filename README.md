## ✨ 한눈에 보기

| 구분 | 내용 |
|---|---|
| 🎮 대상 게임 | HOPE 01 (Construct 3 + WebView2 기반) |
| 📝 번역 범위 | 대사・선택지・아이템・퀘스트・업그레이드・튜토리얼・표지판・메뉴・엔딩 + 이미지 속 글자까지 |
| 🈶 폰트 | 한글 전용 픽셀 폰트(갈무리・네오둥근모) 자동 적용 |
| 💿 설치 | `.bat` 파일 하나 실행 → 자동 탐색 → 메뉴에서 **설치** 선택 |
| 🗑️ 제거 | 같은 파일 재실행 → 메뉴에서 **제거** (원본 자동 복구) |
| 🖥️ 지원 환경 | Windows / 스팀덱(SteamOS) |
| 🔄 업데이트 확인 | 실행할 때마다 새 버전 유무를 조용히 확인 *(자동 설치는 안 함)* |

---

## 🛡️ 안전장치

- ✅ 설치・제거 시 원본 파일 **자동 백업**
- ✅ 설치할 때마다 **세이브 파일도 자동 백업**
- ✅ 패치 파일 **손상 여부 사전 점검**
- ✅ 게임이 살짝 업데이트돼도 **설치가 막히지 않음**
- ✅ 오래된 세이브의 텍스트 캐시 문제도 설치할 때 **자동 복구**

---

> [!WARNING]
> - 비공식 팬 번역이라 오역・표시 오류가 있을 수 있으며, 게임 자체 결함(흰 화면 멈춤 등)까지 책임지지는 않습니다
> - 앞서해보기 특성상 업데이트가 잦아, 업데이트 후 일시적으로 다시 영어로 보일 수 있습니다 → **패치 재실행**으로 해결
> - 서명되지 않은 개인 배포 파일이라 보안 경고가 뜰 수 있지만, 개인정보 수집 등의 동작은 하지 않습니다
