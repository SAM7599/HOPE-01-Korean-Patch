# HOPE 01 한국어 패치 배포 종료 안내

안녕하세요, HOPE 01 한국어 비공식 패치를 만들어온 제작자입니다.

오랫동안 이 패치를 사용해주시고, 버그를 제보해주신 모든 분들께 먼저 감사드립니다.

## 배포를 종료합니다

최근 "메인 메뉴 버튼, NPC 대화창, 튜토리얼 안내창 등의 글자가 안 보인다"는 제보를 받고 끝까지 원인을 파봤는데, 결론적으로 **이 게임 엔진 자체에 박혀있는 한계**라는 것을 확인했습니다. 외부 패치 파일(번역 데이터)을 아무리 수정해도 고칠 수 없는 문제라, 더 이상 패치로 해결할 방법이 없다고 판단해 배포를 종료합니다.

## 원인 (기술적으로 확인된 내용)

게임은 일부 UI 텍스트(메인 메뉴 버튼, NPC 대화창, 튜토리얼 안내창, 아이템 설명, 설정 메뉴, 제작대 텍스트 등)를 **SpriteFont2**라는 비트맵(픽셀) 폰트 방식으로 그립니다. 이 방식은 글자 하나하나를 이미지 아틀라스의 특정 칸에서 잘라와 그리는데, 각 글자가 몇 번째 칸에서 잘라올지는 "이 폰트가 지원하는 글자 목록(charset)" 문자열 안에서 그 글자가 몇 번째에 있는지로 정해집니다.

원본(영문) 게임의 해당 글자 목록은 길이가 **정확히 53자**(A-Z, 숫자, 몇 가지 기호)입니다. 한국어 패치를 만들면서 이 목록에 한글 음절(약 1,087자)을 추가로 덧붙였는데, 실제 게임을 실행해보면:

- 목록의 **0~52번째 자리**(원래 영문 53자)에 있는 글자는 정상적으로 그려집니다.
- 목록의 **53번째 자리부터 추가된 글자는, 그게 한글이든 그냥 특수기호(`$` `%` `*` `=` `~` 같은 평범한 ASCII 기호)든 상관없이 전부 안 보입니다.**

특수기호로 직접 테스트해서 확인했기 때문에, "한글이라서" 안 보이는 게 아니라 **"원래 영문 53자 목록 길이를 넘어가는 자리에 있는 글자는 무엇이든 안 보인다"**는 것이 명확합니다. 즉 게임이 내부적으로 이 글자 목록을 원래 길이(53)만큼만 읽어들이도록 고정되어 있고, 패치로 아무리 `data.json`의 글자 목록 문자열을 늘려도 실제로는 그 늘어난 부분이 적용되지 않는 것으로 보입니다.

이건 게임을 실행하는 바이너리(엔진) 내부의 동작이라, **외부에서 텍스트/이미지 파일만 바꿔서는 고칠 수 없는 영역**입니다. 개발자가 직접 SpriteFont2 관련 코드를 수정해야 해결 가능합니다.

## 지금까지의 시도

이 결론에 도달하기까지 다음과 같은 것들을 확인/시도했습니다.

- 폰트 이미지(아틀라스) 자체는 한글 글리프가 정상적으로 포함되어 있음을 직접 확인
- 인스턴스에 저장된 글자 목록이 폰트 리소스의 글자 목록과 정확히 일치함을 확인
- 해당 UI에 걸려있던 화면 효과(ScanLines, Noise, WarpObject)를 모두 제거해봤지만 변화 없음
- 영어 텍스트로 바꾸면 정상적으로 보이는 것을 확인 (버튼 5개는 이 방식으로 임시 조치)
- 글자를 한글 목록의 맨 앞/중간/맨 뒤에 둬도 전부 동일하게 안 보임 (목록 내 위치와 무관)
- 한글이 아닌 순수 특수기호(`$` `%` `*` `=` `~`)로도 동일하게 재현됨 → 원래 53자 길이를 넘는 자리의 문제로 최종 확인

웹뷰(WebView2) 디버깅 콘솔을 통해 더 정확한 오류 메시지를 보려고도 했으나, 이 게임은 F12, 환경변수, 레지스트리 정책, Steam 실행 옵션 등 일반적인 방법으로는 디버깅 포트가 열리지 않도록 막혀있어 접근할 수 없었습니다.

## 게임 개발사(BendingBoyGames)께

이 문서를 읽으시는 개발자분이 계시다면, SpriteFont2 플러그인(또는 커스텀 텍스트 렌더링 로직)이 글자 목록(charset) 길이를 원본 영문 53자 기준으로 고정해서 읽어들이고 있을 가능성을 확인해주시면 감사하겠습니다. 이 부분만 해결되면 한국어뿐 아니라 영어 외 다른 언어 로컬라이징도 가능해질 것으로 보입니다.

## 마지막으로

패치를 아껴주신 모든 분들께 다시 한번 감사드립니다. 끝까지 원인을 찾아보려 했지만, 여기서부터는 게임 엔진을 직접 고칠 수 있는 개발자의 영역이라 개인 취미로 만드는 비공식 패치로는 더 진행하기 어렵다고 판단했습니다.

기존에 배포된 버전은 계속 다운로드하실 수 있지만, 위 문제(일부 UI 텍스트가 안 보이는 현상)는 해결되지 않은 상태로 남아있을 수 있음을 양해 부탁드립니다.

그동안 감사했습니다.
